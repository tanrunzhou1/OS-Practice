# Unix风格文件系统 - 产品需求文档 (PRD)

---

## 一、产品定位

### 1.1 产品概述

本产品是一个基于i-node的Unix风格虚拟文件系统模拟器，旨在内存中模拟真实的Unix文件系统架构。该系统将16MB内存空间虚拟化为磁盘存储，支持文件创建、删除、目录管理、空间查询等核心功能，为学习和理解Unix文件系统内部原理提供实践平台。

### 1.2 目标用户

- 计算机科学专业学生（操作系统课程）
- 对文件系统原理感兴趣的开发人员
- 需要理解i-node和块分配机制的学习者

### 1.3 核心价值

- 直观展示Unix文件系统的内部工作机制
- 提供完整的文件系统操作接口
- 支持持久化存储，可重新加载

## 二、核心功能列表

### 2.1 系统初始化模块

| 功能名称 | 功能描述 |
|---------|---------|
| 内存空间分配 | 分配16MB连续内存作为虚拟磁盘空间 |
| 块划分 | 将16MB空间划分为1KB大小的块（共16384个块） |
| 超级块初始化 | 初始化超级块，记录文件系统元信息 |
| i-node位图初始化 | 初始化i-node位图和空闲块位图 |
| 根目录创建 | 创建根目录"/"，使用第1个i-node |

### 2.2 文件操作模块

| 功能名称 | 功能描述 |
|---------|---------|
| createFile | 创建新文件，指定文件名和大小（KB），自动分配i-node和数据块 |
| deleteFile | 删除指定文件，释放占用的i-node和数据块 |
| cat | 读取并显示文件内容（随机字符串） |
| cp | 复制文件，创建文件的副本 |

### 2.3 目录操作模块

| 功能名称 | 功能描述 |
|---------|---------|
| createDir | 创建目录，支持嵌套目录结构 |
| deleteDir | 删除空目录，不允许删除当前工作目录 |
| changeDir | 切换当前工作目录 |
| dir | 列出当前目录下的所有文件和子目录，显示至少2个属性（文件大小、创建时间） |

### 2.4 系统管理模块

| 功能名称 | 功能描述 |
|---------|---------|
| sum | 显示存储空间使用情况（已用块数、空闲块数） |
| 欢迎信息 | 启动时显示团队成员信息（姓名、学号）作为版权声明 |
| exit | 退出程序，将内存数据持久化到磁盘文件 |

## 三、用户使用流程

### 3.1 首次使用流程

```
启动程序 → 初始化16MB虚拟空间 → 显示欢迎信息 → 进入交互命令行
```

### 3.2 交互流程图

```
┌─────────────────────────────────────────────────────────────┐
│                      用户交互流程                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   ┌──────────────┐    ┌──────────────┐    ┌─────────────┐ │
│   │ 输入命令      │───>│ 解析命令     │───>│ 执行操作    │ │
│   └──────────────┘    └──────────────┘    └─────────────┘ │
│                                                 │           │
│   ┌──────────────┐    ┌──────────────┐          │           │
│   │ 显示结果     │<───│ 处理返回     │<─────────┘           │
│   └──────────────┘    └──────────────┘                      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 3.3 命令使用示例

```bash
# 1. 创建目录结构
createDir /dir1
createDir /dir1/sub1

# 2. 创建文件
createFile /dir1/myFile 10    # 创建10KB的文件

# 3. 查看目录内容
dir                          # 列出当前目录文件

# 4. 切换目录
changeDir /dir1

# 5. 复制文件
cp myFile backupFile

# 6. 查看文件内容
cat /dir1/myFile

# 7. 查看空间使用
sum

# 8. 删除文件
deleteFile /dir1/myFile

# 9. 删除目录
deleteDir /dir1/sub1

# 10. 退出系统（自动保存）
exit
```

## 四、功能详细说明

### 4.1 createFile 命令

- **命令格式**：`createFile fileName fileSize`
- **参数说明**：
  - `fileName`：文件路径（支持绝对路径和相对路径）
  - `fileSize`：文件大小（单位：KB）
- **功能描述**：在指定位置创建新文件，自动分配i-node和数据块，文件内容使用随机字符串填充
- **错误处理**：当fileSize > 266KB时，输出错误信息

### 4.2 deleteFile 命令

- **命令格式**：`deleteFile filename`
- **功能描述**：删除指定文件，释放占用的i-node和数据块
- **错误处理**：文件不存在时输出错误信息

### 4.3 createDir 命令

- **命令格式**：`createDir dirPath`
- **功能描述**：创建新目录，支持嵌套目录结构
- **错误处理**：父目录不存在或目录已存在时输出错误信息

### 4.4 deleteDir 命令

- **命令格式**：`deleteDir dirPath`
- **功能描述**：删除指定空目录
- **限制**：不允许删除当前工作目录
- **错误处理**：目录非空或为当前目录时输出错误信息

### 4.5 changeDir 命令

- **命令格式**：`changeDir dirPath`
- **功能描述**：切换当前工作目录
- **错误处理**：目录不存在时输出错误信息

### 4.6 dir 命令

- **命令格式**：`dir`
- **功能描述**：列出当前目录下的所有文件和子目录
- **显示属性**：至少显示文件大小和创建时间两个属性

### 4.7 cp 命令

- **命令格式**：`cp sourceFile destFile`
- **功能描述**：复制文件，创建文件的副本
- **错误处理**：源文件不存在时输出错误信息

### 4.8 sum 命令

- **命令格式**：`sum`
- **功能描述**：显示存储空间使用情况
- **显示信息**：总块数、已使用块数、空闲块数、使用百分比

### 4.9 cat 命令

- **命令格式**：`cat filePath`
- **功能描述**：打印文件内容到终端
- **错误处理**：文件不存在时输出错误信息

### 4.10 exit 命令

- **命令格式**：`exit`
- **功能描述**：退出程序，将内存中的文件系统数据持久化到磁盘文件
- **后续**：可重新加载继续使用
